# Data

Raw OASIS-3 participant-level data are not included in this repository.

The OASIS-3 dataset is available through the OASIS Brains project under an approved data use agreement:

https://www.oasis-brains.org/

This repository provides analysis scripts, Stan models, simulation code, and manuscript-ready summary outputs. Users who wish to reproduce the OASIS-3 application should obtain the required data directly from OASIS and place the files locally before running the preprocessing scripts.

Large intermediate files, fitted Stan objects, posterior draws, and CmdStan output directories are intentionally excluded from version control.
